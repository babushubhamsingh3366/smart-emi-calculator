# Smart EMI Calculator

* Calculate Total Interest Payable

## How EMI is Calculated

EMI is calculated using the standard formula:

EMI = P × R × (1 + R)^N / ((1 + R)^N − 1)

Where:

* P = Loan Amount
* R = Monthly Interest Rate
* N = Loan Tenure in Months
